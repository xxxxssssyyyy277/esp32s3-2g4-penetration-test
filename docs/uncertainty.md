# 测量不确定度与检测门限

## Summary

用 RSSI 差分法测穿透损耗时，能分辨的最小损耗由三项决定：RSSI 的 1 dB 量化、室内多径引起的起伏、以及基准本身的漂移。按本仓库的采样参数（N = 50、σ ≈ 2.5 dB），单点标准不确定度为 0.53 dB，两点之差的合成标准不确定度为 0.75 dB，检测门限（α = 0.05、功效 0.80）为 2.1 dB。低于 2.1 dB 的差异只能表述为「不可分辨」，不应给出具体数值。

> **同源提示**：本文与作者课程报告的第 3.6 节（不确定度与门限）及第 3.7 节（采样量分配）同源，是同一次工作的两种载体。改动此处时请同步报告，反之亦然——两处口径不一致比缺文档更难排查（本项目已发生过一次：「远离饱和区」与「未作标定」并存）。

## 记号

| 符号 | 含义 | 本仓库取值 |
|---|---|---|
| `N` | 每测点样本数 | 50（`APP_MEAS_N_DEFAULT`） |
| `σ` | 单测点 RSSI 标准差（多径引起） | 2.5 dB，典型值，**非实测** |
| `σ_med` | 中位数的标准误 | 由 `σ`、`N` 算出 |
| `σ_L` | 穿透损耗的标准不确定度 | 由两侧合成 |
| `Δ_min` | 检测门限（最小可判差异） | 由 `σ_L` 与功效算出 |

## 中位数的标准误

对正态分布，样本中位数的标准误近似为

```
σ_med ≈ 1.2533 · σ / √N
```

取 `σ = 2.5 dB`、`N = 50`，得 `σ_med ≈ 0.44 dB`。

## 量化分量

RSSI 是 8 位整数、步进 1 dB。量化误差按均匀分布折算：

```
σ_q = 0.5 / √3 ≈ 0.29 dB
```

## 合成

单点合成（中位数统计 + 量化）：

```
σ_point = √(0.44² + 0.29²) ≈ 0.53 dB
```

穿透损耗是基准与测点两个中位数之差，两侧独立：

```
σ_L = √(σ_base² + σ_case²) ≈ √2 × 0.53 ≈ 0.75 dB
```

取包含因子 `k = 2`，扩展不确定度约 `±1.5 dB`。

> 若基准取首尾两次（`n_base = 100`），`σ_L` 可降到 0.68 dB、扩展 `±1.4 dB`。
> 本仓库的 `analyze.py` 用的是首尾平均，但为避免结论依赖基准测次的偶然性，文档与报告统一按 0.75 dB 计。

## 检测门限

不确定度描述「这把尺子有多准」，门限描述「用这把尺子能判出多小的差别」。等方差、双侧检验下：

```
Δ_min = (z_{1-α/2} + z_{1-β}) · σ_L
```

| α | 功效 | 系数 | Δ_min |
|---|---|---|---|
| 0.05 | 0.80 | 2.80 | **2.1 dB** |
| 0.05 | 0.95 | 3.61 | 2.7 dB |

## 量化地板：门限压不下去的那个值

`Δ_min` 并非随样本数无限下降。令 `N → ∞`，统计项消失，只剩量化项：

```
Δ_min(∞) = (z_{1-α/2} + z_{1-β}) · √2 · σ_q
         = 2.80 × 1.414 × 0.289
         ≈ 1.14 dB
```

**这是一个硬地板**：无论平均多少次，本方法都分辨不出小于 1.14 dB 的差异（α = 0.05、功效 0.80）。

这一点在实务上很容易被忽略。看到「纸介质只变化不到 1 dB」，直觉是「多测几次就能测出来」——但 0.8 dB 已经在地板之下，**增加样本数无效**。

要突破地板只有三条路，且都不是"多测"：

1. 降低量化步长（改用 CSI 幅度、或读取更细的 RSSI 分辨率）
2. 换用对功率更敏感的量（信道估计、EVM）
3. 累积长时间驻留以换取更细的有效分辨率（代价是环境漂移）

`analyze.py` 的 `VERDICT_TOL_DB = 3.0` 建在这个地板之上——它比地板宽约 2.6 倍，属于宽松判定，不应被理解为"能分辨 3 dB"。

## 中位数的效率代价

对高斯噪声，中位数的渐近相对效率为 `2/π ≈ 0.637`，同样本量下其标准误是均值的 1.2533 倍。
要追平均值的精度，`N` 需从 50 增至约 79。

折中方案是 10% 截尾均值，效率接近均值（约 0.97）而仍保留抗野值能力。
深衰落条件下中位数仍是更稳的选择，这一效率损失可以接受，但应当记录。

## 采样量怎么分配

上面的公式回答「给定 `N`，门限是多少」。反过来的问题在工程上更有用：**给定可用的采集时间，样本该怎么分？**

设第 `i` 个测点采集 `n_i` 次、单次耗时 `τ`，共 `M` 个测点，约束为 `Σ n_i·τ ≤ T`。第 `i` 点的门限为

```
δ_i(n_i) = 2.80 · √2 · √( (1.2533σ/√n_i)² + σ_q² )
```

要求能分辨目标效应量 `δ_i`，令 `δ_i(n_i) ≤ δ_i`，先忽略量化项：

```
n_i ≳ (4.96 · σ / δ_i)²
```

即**所需样本数与待分辨效应量的平方成反比**：门限减半，样本数要增到四倍。

### 本仓库的 `N = 50` 是怎么来的

取 `σ = 2.5 dB`、目标 `δ = 2.1 dB`（即 4 号水介质量级的最低可判门限）：

| 条件 | 所需 N |
|---|---|
| 忽略量化项 | 34.9 ≈ 35 |
| 计入 `σ_q = 0.29 dB` | 49.6 ≈ 50 |

固件的 `APP_MEAS_N_DEFAULT = 50` 正是按后者取的。反过来说，**量化使所需样本数增加了约 43%**——如果 RSSI 不是 8 位整数，35 次就够了。

### 两条分配原则

1. **目标效应量相同时，等分样本即最优**（min-max 意义下）。当前 `capture.py` 对每个测点用同样的 `N`，符合这一结论。
2. **某测点的预期效应明显更小时，不要靠"多测几次"挽回**——收益会被量化地板截断。可行的是降低该点的精度要求，或把样本让给更需要分辨的测点。

## 用实测值替换假设

固件 `#SUMMARY` 输出带有逐点 `stdev` 字段（`board b/main/measure.c`），把它代入 `σ` 即可得到该点的实测不确定度，不必使用 2.5 dB 这个典型值。公式不变。

## 使用规则

1. 差异小于 `Δ_min`（2.1 dB）的测点，只能报告「不可分辨」，不应给两位小数。
2. 要把门限压到 1 dB 以下，需同时增大 `N`、抑制多径、并消除 1 dB 量化（例如改用 CSI 幅度）。单靠增加采样数只能压低统计项，压不到 1.14 dB 以下。
3. 报告结果时同时给出 `σ_L` 与 `Δ_min`。只给中位数不足以说明结论的可信度。

## 如何复核

本页出现的每一个数都可以复算，不必手工验算：

```
wolframscript -file docs/verify_numbers.wls
```

脚本逐条对照断言（不是打印一堆数字让人自己比），任一条超出容差即以**退出码 1** 结束，可直接接入 CI。当前 25 项全部通过。

需要 Wolfram Engine 12.0+，开发者许可免费。输入参数 `sigma` 与 `N` 在脚本开头，改这两个值即可复算换参数后的情形。
