# 测量原理

## Summary

本仓库测的不是材料的电参数，而是**同一条链路在加遮挡前后的接收电平差**。方法上属于替代法：两次测量相减时，发射功率、天线增益、路径损耗全部抵消，剩下的才是遮挡引入的附加衰减。理解这一点，才知道这些数值能说什么、不能外推到什么范围。

> **同源提示**：本文与作者课程报告的第 3.5 节（RSSI 的闭环取得与饱和）及第 4.4 节（全屏蔽导致链路中断）同源，是同一次工作的两种载体。改动此处时请同步报告，反之亦然。

## 被测量是什么

接收功率可写成

```
Prx = Ptx + Gtx + Grx − FSPL(d) − L_extra
```

其中 `L_extra` 是遮挡引入的附加衰减，`FSPL(d) = 20lg(4πd/λ)` 是自由空间损耗。

基准与测点各做一次测量，两式相减：

```
L = Prx(基准) − Prx(测点) = L_extra
```

`Ptx`、`Gtx`、`Grx`、`FSPL(d)` 在两次测量中相同，**全部消去**。

这就是本方法的全部要点：**它不需要知道发射功率是多少，只需要保证两次测量"除了遮挡物之外都一样"**。

## 因此它给出的是什么

| 能说 | 不能说 |
|---|---|
| 这条链路加遮挡后多衰减了 `L` dB | 该材料的衰减常数 α |
| 两种遮挡物哪个衰减更大、差多少 | 该材料的复介电常数 |
| 某效应是否大于本方法的检测门限 | 该损耗在别的工作频率下的值 |

`L` 的可复现性绑定在**具体几何**（间距、天线朝向、板型、信道）上。换一套装置，同一个 25 cm、同一批材料的 `L` 会变，因为近场耦合与多径结构变了。

## 读数从哪来：AGC 闭环

RSSI 不是"功率计读数"，而是接收机**闭环调节的结果**。

接收机通过自动增益控制（AGC）把中频电平维持在模数转换器的工作区间内。该回路是一个负反馈：功率检测给出实际电平与目标电平之差，控制器据此调整可变增益，使输出回到工作点。稳态时增益与输入功率近似互为倒数，输出恒定于工作点附近，而 RSSI 由稳态增益反推得到。

由此存在三个工作区：

| 工作区 | 条件 | RSSI 的表现 |
|---|---|---|
| 可调区 | 输入落在动态范围内 | 与接收功率近似成正比 |
| 上饱和 | 输入过强，增益已到下限 | 读数被钳位，功率增量被抹平 |
| 下饱和（失锁） | 输入低于解调门限 | 帧无法解出，**不产生读数** |

> 上表是接收机的通用行为。**本仓库未对 ESP32-S3 的 AGC 动态范围上下限与环路时间常数作标定**，因此不给出具体数值。要用到这些量，需自行测量。

## 三个直接后果

1. **差值法只在两次测量都落在可调区时成立。** 若基准接近上饱和而测点不是，差值里会混入增益压缩的贡献。
2. **完全屏蔽时表现为「没有读数」而非「读数很小」。** 输入低于解调门限，回路无从建立，此时 RSSI 是解帧的副产物，没有帧就没有值。这是 `#SUMMARY` 在屏蔽工况下缺失的原因，不是采集失败。
3. **环路的调节时间若短于采样间隔，缓慢变化会被增益吸收一部分。** 读数因此显得平稳，但也意味着部分真实变化不会完整反映到 RSSI 上。

## 与计量学方法的关系

| 方法 | 测什么 | 可溯源 |
|---|---|---|
| 自由空间法（VNA + 双喇叭 + 时域门） | S21 → εr | 有 |
| 波导法 / 同轴法 | S11 / S21 → εr、μr | 有 |
| **本仓库的 RSSI 差分法** | **电平差** | **无** |

本方法没有标准件对照，属于**比较测量**而非计量意义上的材料参数测量。它的价值在于**便携、低成本、能判断"某个遮挡物到底有没有影响"**，而不在于给出材料的本征参数。

## 一条判断用的问法

**问：这个数是绝对量还是相对量？**

- 相对量（差分）→ 不需要溯源，但只能比较，不能报材料参数
- 绝对量 → 必须溯源到标准件

本仓库全部结果属于相对量。所以 `L = 3 dB` 必须读成「相对基准多衰减了 3 dB」，而不是「材料衰减是 3 dB」。
